{{ include "weebo-operator.notes" . }}

1. Connect a Openbao with an API token:

     kubectl -n {{ .Release.Namespace }} create secret generic openbao-admin --from-literal=token=<token>

     kubectl apply -f - <<YAML
     apiVersion: openbao.weebo.io/v1alpha1
     kind: OpenbaoInstance
     metadata:
       name: main
     spec:
       url: https://openbao.example.com
       tokenSecretRef:
         namespace: {{ .Release.Namespace }}
         name: openbao-admin
         key: token
     YAML

2. Then declare OpenbaoObject resources referencing it
   (`spec.instanceRef: main`).

Argo CD: paste the health check of the
{{ include "weebo-operator.fullname" . }}-argocd-health ConfigMap into argocd-cm under
`resource.customizations.health.openbao.weebo.io_*`.
